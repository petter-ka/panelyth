# Stage 08.5 — Viewer Settings + Interaction Polish

Status: **Implementation complete — verification pending** (2026-10-01). Automated tests were not added or run.

## Objective

Give users a clear settings surface for viewer behavior and startup preferences, with accessible controls that match
FastView's existing visual system.

## Scope

- Settings modal with Viewer, Appearance, and Shortcuts tabs. Appearance includes a three-step font and spacing control
  (S / M / L).
- Viewer preferences persisted in `library.db`:
  - startup folder: last used, specified folder, or system default (Home)
  - confirm before exiting through Escape
  - confirm before replacing files
  - remind about unsaved changes
  - mouse wheel: previous/next image or zoom
- An explicit “Paste and overwrite conflicts” action, confirmed when the overwrite preference is enabled.
- Switch controls for on/off preferences and a visible Ctrl+wheel zoom hint in previous/next mode.
- Escape closes an open image viewer or exits video fullscreen first; otherwise it requests app exit and follows the
  user's confirmation preference.
- Double-clicking the focused image or video area closes its full-screen view.
- Start in the configured folder when the library becomes available.
- Arrange the workspace as a left column with the folder tree above preview and content on the right; both dividers resize
  and persist independently.

## Non-goals

- Image editing or unsaved image changes; current image transforms only affect display.
- Replacement choices on “Copy to” and “Move to”; these actions continue to keep both files on conflicts.
- Settings unrelated to the viewer and app appearance.

## APIs/contracts

- Settings use the existing `library.setSetting` method under the `viewer` key.
- Interface size uses a localStorage preference and applies before the first render to avoid a layout jump.
- App exit is a typed, sender-validated main-process IPC method.
- Image navigation remains in the renderer; wheel navigation is local to the focused image viewer.

## Acceptance criteria

- Settings can be opened from the status bar and navigated by tabs.
- Appearance lets users choose S, M, or L; the choice scales text, padding, and spacing and persists across restarts.
- Switches expose state accessibly and save changes to the library settings.
- Startup folder and wheel behavior follow the saved preference.
- Escape keeps its viewer/fullscreen behavior and requests app exit only outside those contexts.

## Risks

- The overwrite switch applies to the explicit paste-replacement action; regular paste and “Copy to” / “Move to” keep both
  files on name conflicts. The save reminder is persisted but cannot trigger until image editing exists; current
  transforms do not modify files.
- The system default is the platform Home place exposed by Electron.
