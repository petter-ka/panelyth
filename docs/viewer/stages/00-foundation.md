# Stage 00 — Foundation

Status: **Complete** (2026-09-30)

## Objective

Create the executable architecture without implementing the complete image viewer.

## Scope

- pnpm workspace: `src/shared/desktop`, `src/viewer/renderer`, `src/shared/contracts`, `src/shared/sidecar`,
  `src/shared/e2e`, `bench`, and build scripts (ADR-0013)
- Electron: BrowserWindow with secure webPreferences, sandboxed preload, `app://` protocol with CSP,
  sidecar lifecycle (spawn, handshake, bounded restarts, ordered shutdown), process logging
- React: application shell (static three-region layout), empty/loading/error states, grid placeholder,
  theme shell (Tailwind tokens, light/dark/system)
- Go: process entrypoint, framed RPC, `system.ping`/`system.info`/`system.shutdown`, structured
  logging, graceful shutdown (request, stdin EOF, signals), bounded worker pool
- Benchmark harness for startup, idle memory, IPC and shutdown

## Non-goals

Folder opening, scanning, SQLite, previews, thumbnail/media protocols, resizable panes, shadcn components,
packaging. Everything that touches files starts in Stage 01.

## Benchmarks

Command: `pnpm bench:startup` (the Stage 00 JSON was overwritten by the Stage 01 run before results were filed per stage; the table below is the Stage 00 record). Go micro-benchmarks:
`…-go-bench.txt`). Environment: Windows 11 26200, i9-13900K (32 threads), 64 GB, Electron 44.5.1,
Chromium 152, Go 1.27.0, production renderer unpackaged, 10 runs.

| Metric | Result | Budget | Verdict |
|---|---|---|---|
| main start → `ready-to-show` | p50 230 ms, p95 245 ms | < 1000 ms | pass |
| main start → sidecar `hello` | p50 83 ms, p95 100 ms | < 500 ms | pass |
| Idle memory, all processes (10 s idle) | 329 MB (sidecar 7.5) | < 400 MB | pass |
| …over empty Electron window (295 MB) | +34 MB | < 60 MB | pass |
| `system.ping` round trip, sequential | p50 0.1 ms, p95 0.2 ms | p95 < 3 ms | pass |
| `system.ping`, 32 concurrent | p95 0.9 ms, ~53k req/s | — | baseline |
| 64 KB echo relay | p50 0.6 ms, p95 0.9 ms | — | baseline |
| App quit → sidecar exited | p50 3.8 ms, p95 5.7 ms; 0 orphans (whole app close p50 84 ms) | < 1000 ms | pass |
| Go `FrameRoundTrip` / `DispatchPing` / `workpool.Submit` | 30 ns / 5.1 µs, 18 allocs / 240 ns, 0 allocs | — | baseline |

Memory budget recalibration: the provisional "< 250 MB" budget was below the platform floor. An empty
sandboxed Electron 44 window measures about 300 MB on this machine (`src/shared/bench/empty-electron`, measured in the same run),
so the budget is now an absolute ceiling plus a Panelyth-attributable delta.

## Post-stage changes

- Theme design: neutral-surround tokens, safelight amber accent, dark default (`docs/shared/DESIGN-SYSTEM.md`,
  ADR-0014). Renderer tests grew to 31 (20 token/contrast checks) and e2e to 8 (fresh profile opens dark;
  theme persists across restarts).
- `PANELYTH_USER_DATA_DIR` (unpackaged only) isolates the Electron profile per e2e/benchmark launch.
- Benchmark fix: sidecar-exit time is now polled concurrently with `app.close()`. The originally recorded
  "p95 71 ms" measured the whole Electron close, not the sidecar. The table above holds the re-run numbers
  (fresh profile per launch, theme changes included).
