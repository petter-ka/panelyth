# Panelyth Showcase

A standalone React landing page for the Panelyth product family. Panelyth is a local-first photo and video viewer; Panelyth Commander is a planned keyboard-first, dual-panel file manager. The page has its own package manifest and nested pnpm workspace, with no imports from the repository's apps or shared packages.

## Run it

```sh
pnpm install
pnpm dev
```

Create a static site bundle with `pnpm build`; preview it with `pnpm preview`.

The product-window mockup and image areas are CSS-built placeholders, ready to be replaced with real screenshots and photography.
