# Stage 05 — Filesystem UX + Navigation + Search + Sort

## Objective

Create the desktop power-user workspace.

## Work

- three resizable panes
- drive/volume enumeration
- quick access
- bookmarks
- recent
- lazy folder tree
- breadcrumbs
- back/forward/up/refresh
- mouse + keyboard navigation
- search scoped to current folder
- recursive-search option
- filters
- multi-key sort
- ascending/descending
- large/medium/small thumbnails
- compact list
- detailed list
- context menus
- properties
- multi-selection

## Acceptance

- folder navigation works by mouse and keyboard
- sidebar remains lazy on huge filesystems
- search and sort are index-backed
- pane resize is smooth
- workspace persists
