# Stage 04 — Full Viewer

## Objective

Open images in a focused viewer while preserving grid responsiveness.

## Work

- selected file -> viewer
- fit mode
- 1:1 mode
- zoom
- next/previous
- keyboard controls
- close/back
- viewer preview profile
- progressive full-image loading

## Acceptance

- changing images feels immediate when cached
- large image decode does not freeze the grid
- failed decode is recoverable
