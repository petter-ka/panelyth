# Stage 05 — Filesystem UX, Navigation, Search and Sort

## Objective

Turn the content browser into a power-user file/media navigation surface.

## Work

- resizable three-pane shell
- drive/volume discovery
- lazy sidebar tree
- quick access
- recent folders
- bookmarks
- breadcrumb
- back/forward/up
- refresh
- keyboard navigation
- search scoped to current folder
- optional recursive search
- filters
- multi-key sorting
- ascending/descending
- large/medium/small thumbnail modes
- compact list mode
- detailed list mode
- file properties
- context menus
- multi-selection

## Acceptance

- very large folder remains responsive
- sidebar does not recursively load all filesystem nodes
- search/sort are index-backed
- keyboard navigation works without mouse
- pane sizes persist
